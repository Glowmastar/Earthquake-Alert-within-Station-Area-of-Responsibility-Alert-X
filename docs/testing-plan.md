# Initial Testing Plan

Do not execute operational alerts during repository setup. The later
prototype should support a clearly separated **SAFE TEST MODE**.

## Initial Testing Principles

- Use representative or sanitized earthquake records.
- Use approved test AOR mappings.
- Use test email recipients.
- Do not send development alerts to operational mailing lists.
- Test events inside an AOR.
- Test events outside an AOR.
- Test duplicate events.
- Test updated event records.
- Test missing or invalid geographic information.
- Test email failure handling.

Actual test cases should be finalized only after the source schema and AOR
rules are known.
